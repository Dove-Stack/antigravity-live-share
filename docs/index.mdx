## Architecture at a glance

<Steps>
  1. **Start Live Share**

      The host opens Antigravity and runs *Live Share: Start Session*.

  2. **Create Session**

      The extension creates a room on the collaboration server via `POST /rooms`.

  3. **Connect Participants**

      Host and guests connect over WebSocket with `?room=<id>`.

  4. **Real-Time Synchronization**

      Cursors, selections, and CRDT document updates relay between peers.
</Steps>
